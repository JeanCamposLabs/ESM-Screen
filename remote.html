Backgrounds

Tick the images you want in the rotation (the playlist) — every TV shows the same one and they all switch together. Click an image to preview it; Pin this keeps every screen on it.

Connection

Create it at github.com → Settings → Developer settings → Fine-grained tokens. Two settings are easy to miss: Repository access → Only select repositories → ESM-Screen, and Permissions → Repository permissions → Contents → Read and write. Pushing commits config.json; GitHub Pages republishes it and every TV picks it up within about two minutes.
